تفاصيل الوظيفة ونبذة عن الدور

شركة فالكون لحلول التكنولوجيا في التجمع الخامس بتدور على Senior Frontend Engineer شاطر ومحترف ينضم للتيم التقني. هتشتغل على منصات فنتك وبوابات دفع إلكتروني بيستخدمها مئات الآلاف في مصر، وهتطبق أحدث التكنولوجيز في بناء الواجهات السريعة والمتجاوبة مع كل الشاشات مع تيم مهندسين شاطرين بقيادة م. مينا سمير وم. سامح موريس.

المهام والمسؤوليات الأساسية

  • بناء وتطوير واجهات المستخدم التفاعلية باستخدام React و Next.js و TypeScript بأعلى معايير الكود النظيف.
  • التعاون مع تيم الـ UI/UX لتحويل تصميمات Figma لواجهات حقيقية سريعة بكسل بيرفكت.
  • تسريع أداء الموقع وتحسين تجربة التصفح على الموبايل وسرعة التحميل (Core Web Vitals).
  • الربط السلس مع واجهات الـ REST APIs وخدمات الـ Backend السحابية.
  • مراجعة الأكواد البرمجية (Code Review) ومساعدة المهندسين الجونيور في التيم.

الشروط والمؤهلات المطلوبة

  • خبرة عملية لا تقل عن ٣ سنين في تطوير الواجهات باستخدام React أو Next.js.
  • إتقان كامل لـ JavaScript الحديثة (ES6+)، TypeScript، و CSS المتقدم.
  • خبرة كويسة في التعامل مع Git و GitHub والعمل بمنهجية Agile / Scrum.
  • خريج هندسة حاسبات أو كليات الحاسبات والمعلومات أو ما يعادلها.
  • شخصية متعاونة وشغوفة بالتعلم وحل المشاكل التقنية المعقدة.

المزايا والبدلات اللي هتاخدها

  • راتب شهري مجزٍ جداً بالجنيه المصري (٢٥,٠٠٠ - ٣٨,٠٠٠ ج.م) حسب الخبرة ومستوى الشطارة.
  • تأمين طبي خاص شامل للموظف والأسرة (Family Medical Insurance).
  • نظام عمل مرن Hybrid (يومين عمل من البيت ريموت).
  • بونص سنوي على الأداء وبدل مواصلات للتجمع الخامس.
  • بيئة عمل مريحة تدعم التطور المهني وحضور المؤتمرات والكورسات التقنية.
